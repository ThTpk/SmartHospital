# บริการและฝ่ายของโรงพยาบาล (SmartHospital)

เอกสารนี้กำหนดบริการทั้งหมดของโรงพยาบาลจำลอง ข้อมูลชุดเดียวกันนี้อยู่ใน `web/js/data.js` และเว็บใช้ข้อมูลจากไฟล์นั้นโดยตรง
หน่วยที่มีรหัส **QUEUE** คือหน่วยที่ผู้ป่วยต้องเข้าคิว จึงถูกนำไปจำลองด้วยทฤษฎีแถวคอย

## 1. ฝ่ายและหน่วยบริการ

| กลุ่ม | หน่วยบริการ | หน้าที่ | QUEUE |
|---|---|---|---|
| ส่วนหน้า | ประชาสัมพันธ์ / จุดคัดแยกหน้าโรงพยาบาล | ให้ข้อมูล คัดแยกผู้ป่วยทั่วไปกับผู้ป่วยฉุกเฉิน | – |
| | เวชระเบียน / ลงทะเบียน + ตรวจสอบสิทธิการรักษา | ลงทะเบียน HN ตรวจสิทธิบัตรทอง ประกันสังคม ข้าราชการ และประกันเอกชน | `REG` |
| | ศูนย์นัดหมาย / Call center | นัดหมายและเลื่อนนัด | – |
| ผู้ป่วยนอก (OPD) | จุดคัดกรอง / ซักประวัติ | วัดสัญญาณชีพและซักประวัติ | `TRI` |
| | ห้องตรวจแพทย์ (คลินิกเฉพาะทาง) | อายุรกรรม ศัลยกรรม กุมารเวช สูติ-นรีเวช ออร์โธปิดิกส์ ตา หูคอจมูก ผิวหนัง จิตเวช | `DOC` |
| | ห้องหัตถการ / ทำแผล / ฉีดยา / วัคซีน | ทำหัตถการเล็ก ฉีดยา และให้วัคซีน | `PRC` |
| | ทันตกรรม | ขูดหินปูน อุดฟัน ถอนฟัน | `DEN` |

| | ห้องฉุกเฉิน | กู้ชีพ ทำหัตถการเร่งด่วน และสังเกตอาการ | `ER` |
| | หน่วยรถพยาบาล / EMS 1669 | รับผู้ป่วยจากภายนอก | – |
| ตรวจวินิจฉัย | ห้องปฏิบัติการ / จุดเจาะเลือด | ตรวจเลือดและปัสสาวะ | `LAB` |
| | รังสีวิทยา (X-ray / CT / MRI / US) | ถ่ายภาพทางการแพทย์ | `XRY` |
| | ตรวจคลื่นไฟฟ้าหัวใจ (EKG / Echo) | ตรวจหัวใจ | `EKG` |
| ผ่าตัดและผู้ป่วยใน | คลินิกวิสัญญี / เตรียมผ่าตัด | ประเมินความพร้อมก่อนผ่าตัด | `ANE` |
| | ห้องผ่าตัด | ผ่าตัดใหญ่ ผ่าตัดเล็ก และผ่าตัดแบบวันเดียวกลับ | `OR` |

## 2. ค่าเริ่มต้นของหน่วยที่มีคิว

ค่าที่เป็นตัวหนาคือค่าหลังปรับปรุงตามคำแนะนำของระบบ (ค่าก่อน → ค่าหลัง) ในเว็บสลับดูทั้งสองแบบได้ที่แท็บ "วิเคราะห์คิว" ส่วน "ผลการปรับปรุงตามคำแนะนำ"
ทุกหน่วยกำหนด service time และความแปรปรวน (Exponential / Erlang-4 / คงที่) ได้เอง

## 3. กระบวนการ (process) และลำดับหน่วยที่ผู้ป่วยต้องไป

| Process | λ (ราย/ชม.) | ลำดับ |
|---|---|---|
| ตรวจโรคทั่วไป (OPD) | 24 | REG → TRI → DOC → CSH → PHA |
| ตรวจโรค + ตรวจเลือด | 15 | REG → TRI → LAB → DOC → CSH → PHA |
| ตรวจโรค + เอกซเรย์ | 8 | REG → TRI → DOC → XRY → DOC → CSH → PHA |
| ทำแผล / ฉีดยา | 5 | REG → TRI → DOC → PRC → CSH → PHA |
| ฉีดวัคซีน | 5 | REG → TRI → PRC → CSH |
| ตรวจสุขภาพประจำปี | 4 | REG → TRI → LAB → XRY → EKG → DOC → CSH |
| ทันตกรรม | 4 | REG → DEN → CSH → PHA |
| กายภาพบำบัด | 3 | REG → DOC → PT → CSH |
| ฉุกเฉิน (ER) | 4 | ERT → ER → LAB → XRY → ER → CSH → PHA |
| นอนโรงพยาบาล (Admit) | 2 | REG → TRI → DOC → LAB → ADM → WARD |
| ผ่าตัดแบบวันเดียวกลับ | 1 | REG → ANE → LAB → OR → PACU → CSH → PHA |

## 4. โปรไฟล์ผู้รับบริการ

โปรไฟล์กำหนด 2 อย่าง ได้แก่ สัดส่วนผู้รับบริการแต่ละประเภท (% ของแต่ละ process) และจำนวนผู้มาใช้บริการในแต่ละชั่วโมง (เริ่ม 08:00)
λ ของแต่ละ process = ค่าเฉลี่ยรายชั่วโมง × สัดส่วน ส่วนตัวคูณรายชั่วโมง = จำนวนชั่วโมงนั้น ÷ ค่าเฉลี่ย
ใช้ทั้งในการวิเคราะห์คิว (เลือกวิเคราะห์ที่ค่าเฉลี่ย ชั่วโมงเร่งด่วน หรือชั่วโมงใดก็ได้ และดูตารางภาระรายชั่วโมง) และในการจำลอง 3D
ในเว็บแก้สัดส่วน แก้จำนวนรายชั่วโมง และเปลี่ยนจำนวนชั่วโมงเปิดได้เอง (โปรไฟล์ "กำหนดเอง")

| โปรไฟล์ | ชม. | ราย/วัน | ชั่วโมงเร่งด่วน | ลักษณะ |
|---|---|---|---|---|
| 🏥 วันทำการปกติ | 8 | 600 | 09:00 (110) | สัดส่วนเท่าค่าเดิม (OPD 32%, OPD+Lab 20% …) |
| 🤒 ฤดูไข้หวัด / โรคระบาด | 8 | 720 | 09:00 (130) | OPD 40%, X-ray 14%, ER 9% |
| 👵 คลินิกโรคเรื้อรัง / ผู้สูงอายุ | 8 | 535 | 08:00 (130) | ตรวจเลือดก่อนพบแพทย์ 38%, กายภาพ 10% |
| 📋 แคมเปญตรวจสุขภาพ / วัคซีน | 8 | 610 | 09:00 (120) | วัคซีน 25%, ตรวจสุขภาพ 25% |
| 🚑 ช่วงเทศกาล / อุบัติเหตุ | 12 | 660 | 18:00 (80) | ER 14%, หัตถการ 14%, ผ่าตัด 5% |
| 🗓️ วันหยุด / คลินิกนอกเวลา | 8 | 245 | 09:00 (45) | OPD 45%, ER 18%, ไม่มีตรวจสุขภาพ |
